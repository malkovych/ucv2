Modern and responsive theme for creating professional CV/Resume websites.

== Description ==

UCV Theme is a clean, modern WordPress theme designed specifically for creating professional CV and resume websites. With customizable sections for skills, experience, education, portfolio, and contact information, UCV Theme helps you showcase your professional achievements in a visually appealing way.

Features:
* Modern and responsive design
* Customizable sidebar with background text
* Sections for About Me, Skills, Experience, Education, Portfolio, Blog, and Contact
* Social media integration
* Beautiful animations and transitions
* One-click demo data import
* And more!

== Installation ==

1. In your admin panel, go to Appearance > Themes and click the Add New button.
2. Click Upload Theme and Choose File, then select the theme's .zip file. Click Install Now.
3. Click Activate to use your new theme right away.
4. Navigate to Appearance > Customize to set up the theme.
5. For demo data import, go to Appearance > UCV Theme and click "Import Demo Data".

== Frequently Asked Questions ==

= How do I set up the homepage? =

Navigate to Appearance > Customize > Homepage Settings and configure sections as needed.

= Can I change colors and fonts? =

Yes, go to Appearance > Customize > Colors and Appearance > Customize > Typography.
